When am I free?

A time counts as busy if any of these is on air: any MLB game (all 30 clubs, regular season + postseason), any NFL game (all 32 clubs — preseason, regular season, postseason, Pro Bowl, Super Bowl), the San Jose Earthquakes, Stanford football, Cal football, Warriors basketball, Sharks hockey, the Valkyries (WNBA), or the Westwood One NCAA football radio showcase. 📡 marks the games that are live on Bay Area radio (hover the icon for the station; the "On the radio in the Bay Area today" panel below the timeline lists them). If a game is definitely happening but its kickoff is still TBD — every NFL playoff game, every MLB postseason game, the late-season Saturday doubleheaders, Week 18 — the day is marked NOT FREE — TIME TBD: clearly-labeled estimated windows block the time where a documented pattern exists, and the site reports no free time at all on that day. Days with only conditional playoff possibilities stay UNCONFIRMED and likewise assert no free time. Everything is shown in America/Los_Angeles for Aug 1, 2026 – Feb 28, 2027.

Defaults are researched league averages (MLB 2:44, NFL 3:12, NCAA 3:24, MLS 2:00, NBA 2:18, NHL 2:30, WNBA 2:05; the Super Bowl blocks 3:45). They're editable above. A day on which any tracked game will definitely be played but has no official kickoff yet (NFL playoffs, late-season Saturdays, Week 18, MLB postseason, some Stanford/Cal games) is NOT FREE — TIME TBD: where a documented pattern exists (2025-26 NFL playoff kickoffs, the actual 2025 MLB postseason start times, WWO air times, the league's standard windows) an EST-tagged estimated window blocks the time, and no free time is reported on that day at all (no free windows, no free minutes — the day is simply not free). Days with only conditional playoff possibilities stay UNCONFIRMED — free time is not asserted there either. See Sources & verification for the links.
